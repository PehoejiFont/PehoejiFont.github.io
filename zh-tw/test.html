即時 POJ 字型測試台

直接在瀏覽器切換本機字型或一鍵複製 NFC、NFD 與非正規反向順序字串貼至其他軟體；可開啟 letter-spacing 揭露誤用 liga 的破版，並即時拆解每個字元的 Unicode 編碼。

互動測試區與字碼檢視器

六項快速目視檢查

切換上方預覽字型（或貼到 Word、Pages、Illustrator 等軟體）後，依序檢查以下六點：

  1. 沒有空白方框（□），也沒有個別字母突然變成另一款字型（特別留意 ḿ ǹ、o͘ 的圓點與第八調豎線）。
  2. o͘ 的圓點穩穩落在右上方，尤其檢查大寫 O͘ Ó͘ Ō͘ O̍͘ 與寬調號 ō͘ ô͘ ŏ͘。
  3. i̍ 乾淨去點，第八調短豎線下方沒有殘留圓點（原理說明）。
  4. 第八調短豎線居中對齊於 a̍ e̍ o̍ u̍ m̍ n̍ 與大寫字母正上方。
  5. tńg--khì-o͘h 中的 -- 維持兩條獨立連字號，未合併成破折號。
  6. NFC、NFD 與反向順序外觀完全一致，且加上 letter-spacing 不會破版（隱藏開關陷阱）。

為什麼要測試三種 Unicode 編碼？

按鈕範例（ó͘）測試目的
複製 NFCU+00F3 ó + U+0358多數網頁與輸入法輸出的標準預組形式；驗證字型是否在預組帶調母音上正確設妥 topright 錨點或 ccmp。
複製 NFDU+006F o + U+0301 + U+0358macOS 檔名與 PDF 複製常產生的分解形式；驗證兩個附加符號同時掛載時不會互相碰撞。
複製反向順序U+006F o + U+0358 + U+0301部分序列式輸入法輸出的非正規順序；驗證在不預先依 ccc 重排的引擎下是否仍正確顯示。
